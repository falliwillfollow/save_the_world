# Patch Proposals

This directory holds `PatchProposal` artifacts generated by the CIaC research loop.

A patch proposal is not an automatic mutation. It is a structured implementation intent that links a validated discovery candidate to:

- the artifact that would need to change,
- the provisional model paths affected,
- the scenarios and metrics that must be checked,
- the acceptance tests that must remain true.

Promotion should happen only after validation and simulation comparison.
